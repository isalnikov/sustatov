## Алгоритм субагента (один родственник или одна ветвь)

1. **Идентификация:** ФИО, даты, место, GEDCOM `@I…@`, статус (CONFIRMED / PROBABLE / SIDE).
2. **Семья:** отец, мать, браки, дети, братья/сёстры — с датами и источниками.
3. **Поиск:** GEDCOM → todo.md → VGD grep → web (site:forum.vgd.ru, sarpust.ru, openlist.wiki).
4. **Не выдумывать:** пустые поля = «не найдено» + план поиска в ЦАНО.
5. **Вывод:** JSON-фрагмент для дерева (см. формат ниже).

## Формат записи (для sustatov_tree.md)

```markdown
### ID: sust-XXX — ФИО
- **Рожд.:** … | **Смерть:** … | **Пол:** …
- **Родители:** … | **Браки:** … | **Дети:** …
- **Роль:** прямая / боковая / тёзка
- **Статус:** CONFIRMED | PROBABLE | NOT FOUND
- **Источники:** [ссылки]
- **Примечания:** …
```

## Чеклист качества (оценка субагента /10)

| Критерий | Балл |
|----------|------|
| Все даты/места с источником | 0–2 |
| Родители + дети + братья/сёстры | 0–2 |
| Боковые ветви не смешаны с прямой | 0–2 |
| Ссылки кликабельны, шифры архивов | 0–2 |
| Нет галлюцинаций, статусы честные | 0–2 |

**Порог приёмки: ≥ 8/10.** Иначе — доработка с конкретным списком пробелов.
