## 4. Соединительное звено (через кого двоюродные)

### Гипотеза: через Абрамовых (материнскую линию Сустатовых)

Фамилия Порунов (а не Сустатов) ⇒ связь идёт через **мать** Николая Александровича.

Мать Сустатовых — **Евдокия Абрамова** (1911–1989), дочь **Никиты Ермолаевича Абрамова** и **Анны Фёдоровны (Маркиной)**.

Сыновья **Ермолая Ивановича Абрамова** (деда Евдокии), по метрикам:
- Никита Ермолаевич (брак с Маркиной Анной Фёдоровной)
- Фёдор Ермолаевич (брак 1877)
- Иван Ермолаевич (брак 09.11.1887 с Прокудановой Матроной Михайловной)
- Александр Ермолаевич (брак 10.11.1891 с Макаркиной Еленой Ивановной)
- сестра Агриппина Ермолаевна (брак с Рябовым Дмитрием Степановичем)

**Гипотеза:** сестра Евдокии Абрамовой (дочь Никиты Ермолаевича и Анны Фёдоровны) вышла замуж за Александра Павловича Порунова. Их сын Николай Александрович — двоюродный брат детей Евдокии Абрамовой и Григория Сустатова.

```
Ермолай Иванович Абрамов
 ├─ Никита Ермолаевич + Анна Фёдоровна Маркина
 │    ├─ Евдокия (1911) + Григорий Сустатов (1912)
 │    │    ├─ Василий (1930) ├─ Николай (1936) └─ …
 │    └─ [сестра Евдокии] + Александр Павлович Порунов (1912)
 │         └─ Николай Александрович Порунов (двоюродный брат)
```

### Альтернативная (менее вероятная) гипотеза — через Сустатовых

Если у Григория Васильевича Сустатова (1912) была сестра (не отражена в GEDCOM), вышедшая за Александра Порунова. В GEDCOM у Григория 1912 только братья — Алексей (1913) и Максим (1917), сестёр нет.
