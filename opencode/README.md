# Каталог данных рода Сустатовых (структура)

## Файлы
- `person.template.json` — шаблон JSON-карточки персоны (с полями связей).
- `people/*.json` — по одному файлу на персону (79 записей).
- `index.json` — сводный индекс всех персон.
- `history.md` — история села Кошелиха (Камкина Мордовская).
- `generate.py` — скрипт генерации файлов (данные можно пополнять и перегенерировать).

## Схема идентификаторов

| Префикс | Категория |
|---|---|
| `D` | Прямая линия (D02–D14) |
| `S` | Братья/сёстры прямой линии |
| `C` | Двоюродные/троюродные и боковые ветви |
| `X` | XVII век (Сыресь, Сустатовы Алатыря, князья Еделевы) |
| `SP` | Супруги |
| `F` | Родственники супругов (Ковригины, Королёвы, Абрамовы, Дворниковы) |
| `P` | Поруновы (двоюродные по мемуарам) |

## Поля шаблона (person.template.json)
- `id, surname, given_name, patronymic, full_name, sex`
- `birth / death` (дата, место, причина)
- `status` — CONFIRMED / PROBABLE / HYPOTHESIS
- `category` — direct / sibling / cousin / collateral / spouse / spouse_family / xvii / porunov
- `generation` — номер поколения
- `relation_to_direct_line` — формулировка родства
- `social_estate, occupation, religion`
- `relationships` — father / mother / spouses / children (по id)
- `sources` — список источников (forum/url/archive/book/file)
- `events` — браки, военная служба, смерти, миграции

## Связи (пример)
Прямая линия: D03 Никита → D04 Пётр → D05 Андрей → D06 Иван Андреевич → D07 Иван (~1815) → D08 Иван (~1847) → D09 Иван (~1870) → D10 Василий (~1890) → D11 Григорий (1912) → D12 Василий (1930) → D13 Григорий (1954) → D14 Игорь.

## Происхождение прямой линии
По ревизии 1748 г. (РГАДА ф.350 оп.2 д.114 лл.1262–1267) семья Никиты Иванова — «прибывшие из дворцовой деревни Сыресевой». Переселение в Камкину (Кошелиху) ~1724 г.
